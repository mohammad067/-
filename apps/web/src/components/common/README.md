# Common Composites (`src/components/common/`)

This directory houses molecular components shared across multiple distinct pages and features.

- Implement layout wrappers (e.g., Container, Section, Typography, Skeleton frames, GlassOverlay).
- Standardize cross-cutting UI patterns like Empty States, Loading spinners, and error boundary fallback cards.
- Restrict logic to local presentation behaviors, fully isolated from API endpoints.
