# Face Recognition & Intelligence System

این پروژه برای شناسایی چهره و جستجوی اطلاعات مرتبط با افراد در فضای مجازی طراحی شده است.

## قابلیت‌ها
- **شناسایی از فایل**: عکس فرد را بدهید و در صورت وجود در پایگاه داده، اطلاعات او را دریافت کنید.
- **وب‌کم زنده**: با استفاده از دوربین لپ‌تاپ یا سیستم، چهره‌ها را به صورت زنده شناسایی کنید.
- **جستجوی هوشمند**: تولید لینک‌های جستجوی گوگل و اینستاگرام برای یافتن آخرین اخبار و مکان‌های دیده شده فرد.
- **پایگاه داده محلی**: امکان افزودن افراد و اثر انگشت چهره (Encoding) آن‌ها به سیستم.

## پیش‌نیازها
برای اجرای پروژه باید کتابخانه‌های مورد نیاز را نصب کنید:
```bash
pip install -r requirements.txt
```

## نحوه استفاده

### ۱. شناسایی از روی فایل عکس
```bash
python app.py path/to/image.jpg
```

### ۲. استفاده از وب‌کم (زنده)
```bash
python app.py --webcam
```
در محیط وب‌کم:
- دکمه **S** را بزنید تا عکس گرفته شود و شناسایی انجام شود.
- دکمه **Q** را بزنید تا برنامه بسته شود.

### ۳. افزودن فرد جدید به پایگاه داده
در حال حاضر می‌توانید از ماژول `database.py` برای اضافه کردن افراد استفاده کنید یا به صورت دستی در فایل `data/people.json` اطلاعات و `encodings` آن‌ها را قرار دهید.

## ساختار پروژه
- `app.py`: ورودی اصلی برنامه.
- `face_engine.py`: موتور پردازش و شناسایی چهره.
- `database.py`: مدیریت پایگاه داده افراد.
- `search_engine.py`: تولید لینک‌های جستجو.
- `data/people.json`: محل ذخیره اطلاعات افراد.

## نکات امنیتی و حریم خصوصی
این ابزار صرفاً برای اهداف آموزشی و شبیه‌سازی سیستم‌های امنیتی ساخته شده است. لطفاً در استفاده از آن قوانین حریم خصوصی را رعایت کنید.
