# Shared UI Components

This folder contains framework-agnostic, presentation-only React components. These components do not hold business logic or read directly from feature-scoped stores.

## Subdirectories
- `ui/`: Atom-level primitives (e.g. Button, Input, Checkbox) based on Shadcn UI and customized to match the premium rice store theme.
- `layout/`: Global layout templates and wrappers (e.g., Header, Footer, Sidebar).
- `common/`: Cross-feature molecular composites (e.g. ProductCard, PriceTag, LoadingOverlay).
