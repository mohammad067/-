# Layout Components (`src/components/layout/`)

This directory contains the universal layout containers for the storefront application shell.

## Responsibility
- Implement the premium Navbar/Header,Footer, Navigation Drawer, and Sidebars.
- Provide fluid, elegant, responsive containers with luxury spacing, Apple-level micro-interactions, and visual polishing.
- Read global settings (e.g., active language, theme) without being coupled to individual user data.
