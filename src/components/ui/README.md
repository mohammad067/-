# UI Primitives (`src/components/ui/`)

This directory houses our fundamental design primitives, inspired by Shadcn UI.

## Responsibility
- Implement atomic design components like Buttons, Inputs, Labels, Badges, Switch toggles, and Glassmorphic cards.
- Highly configurable via `class-variance-authority` (cva) and easily styleable with Tailwind CSS classes.
- Completely pure: zero dependence on business logic, React Context (except for component-internal controls), or active stores.
